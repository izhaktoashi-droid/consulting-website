3. Replace the old index.html when GitHub asks.
4. Commit the changes.

SEO note:
The canonical URLs and sitemap currently use the existing GitHub Pages address.
After purchasing and connecting your own domain, update the canonical URLs, Open Graph URLs,
sitemap.xml and robots.txt to the final domain, then add the domain in Google Search Console.
